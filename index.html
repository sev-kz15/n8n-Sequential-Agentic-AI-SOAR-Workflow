Sequential Agentic AI SOAR Platform

How to read the workflow

  1. Layer 1Ingest

    IngestionWazuh posts each security alert to the workflow's webhook.

  2. Layer 2DP-03

    Extract, transform, filterParses the alert, starts the detection clock, and drops anything outside the in-scope detection rules before it reaches an AI agent.

  3. Layer 3DP-01

    Agent 1: threat classificationClassifies the threat type, MITRE ATT&CK technique, severity and confidence using a locally hosted Llama 3.1 8B model.

  4. Layer 4DP-01

    Agent 2: threat investigationValidates Agent 1's classification and decides whether to respond autonomously or escalate to a human analyst.

  5. Layer 5DP-01

    Agent 3: threat responseGenerates the containment command: block the source IP, or disable the offending account.

  6. Layer 6Guards

    Response validationStatic checks confirm the command matches its test case, and a protected-account guard escalates any attempt to disable a privileged account.

  7. Layer 7Execute

    Execution and captureRuns the command on the Domain Controller over SSH, records escalations, and logs timings and outcomes for evaluation.

Environment-specific values (hosts, IP addresses, credentials and cloud resource names) have been replaced with placeholders such as <DC_IP>. This copy is for viewing and will not run as-is.
